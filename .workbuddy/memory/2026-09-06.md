# 2026-09-06

## Omni Code 前端设计体系重构（实色极简 + 双主题）

**决策（用户拍板）**：风格走实色极简（Linear / Vercel 向）；主色调由方案统一配（最终 #5b5bd6 紫蓝）；彻底重构；暗色模式本次就做（跟随系统 + 手动）。

**起因**：原代码三套体系并行 —— `index.css` 的 `@theme` token 几乎零引用、组件里全是 `text-black/60` 硬编码、45 处内联 `rgba()`、圆角四档并存（xl 31 / lg 15 / 2xl 4 / full 12）、语义色 `bg-red-500/10` 与 `bg-red-50` 两套混用。改一个色要动 11 个文件。

**产出**：
- `src/index.css` —— 唯一事实来源。`:root` / `.dark` 两套 CSS 变量 + `@theme inline` 映射为 Tailwind 工具类。命名规则：`surface-*`（中性层）/ `line`（边框）/ `fg*`（文字）/ `accent` / `success|warning|danger|info`，语义色统一三档（主色 / `-subtle` / `-line`）。圆角收成 5 档（xs4 sm6 md8 lg12 xl16）。已删除 `App.css`（原 glass 体系）。
- `src/components/ui/` —— 新增 Button / IconButton / Card / CardHeader / CodeBlock / Field / Input / Textarea / Select / Badge / StatusDot / Modal(Radix Dialog) / Segmented / EmptyState / PageHeader / PageBody / Page / ProgressBar，配 `index.ts` barrel。
- `src/lib/cn.ts`（clsx + tailwind-merge）、`src/lib/theme.ts`（resolveTheme / applyTheme / useThemeEffect，跟随系统）。
- `index.html` 加首屏前主题脚本，读 `omni-code-storage` 避免深色白闪。
- 11 个业务组件样式层全量重写：Sidebar、ChatView、ModelLibrary、MemoryManager、PluginManager、HistoryView、SettingsView、AuthPage、ApprovalCard、TaskExecutor、FileExplorer。业务逻辑与 props 未动。

**验证**：`tsc --noEmit` 零错误；`vite build` 通过（27.3 kB CSS / 315 kB JS）。全仓 grep 确认无残留 glass / text-gradient / 硬编码色值，`--shadow-focus`、`@keyframes scale-in`、`color-mix` 透明度修饰符均正确生成。

**注意**：此环境下 `vite build` 清空 `dist/` 会被沙箱 safe-delete 拦截（`trash` 操作失败），需加 `--emptyOutDir=false`。与代码无关。
